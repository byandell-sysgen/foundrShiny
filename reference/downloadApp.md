# Download App

Download App

## Usage

``` r
downloadApp(id)

downloadServer(id, prefix, main_par, download_list)

downloadOutput(id)
```

## Arguments

- id:

  identifier for shiny reactive

- prefix:

  static prefix for filename

- main_par:

  input parameters from calling routine

- download_list:

  reactiveValues with postfix,plotObject,tableObject

## Value

nothing
