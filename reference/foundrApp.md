# foundr App for foundr package

foundr App for foundr package

## Usage

``` r
foundrApp()

foundrServer(
  id,
  traitData = NULL,
  traitSignal = NULL,
  traitStats = NULL,
  customSettings = NULL,
  traitModule = NULL
)

foundrInput(id)

foundrOutput(id)
```

## Arguments

- id:

  identifier for shiny reactive

- traitData, traitSignal, traitStats, traitModule:

  static objects

- customSettings:

  list of custom settings
