# Setup Data for Foundr App

Setup Data for Foundr App

## Usage

``` r
foundrSetup(
  data_instance = c("Liver", "Trait"),
  data_subset = NULL,
  custom_settings = TRUE,
  dirpath = file.path("~", "founder_diet_study", "HarmonizedData")
)
```

## Arguments

- data_instance:

  type of data

- data_subset:

  focus instance to selected dataset(s) if not \`NULL\`

- custom_settings:

  setup custom if \`TRUE\`

- dirpath:

  path to data directory

## Value

invisible
