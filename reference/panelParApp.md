# Panel Parameters App

Panel Parameters App

## Usage

``` r
panelParApp()

panelParServer(id, main_par, traitStats = NULL, panel_name = NULL)

panelParInput(id)

panelParUI(id)

panelParOutput(id)
```

## Arguments

- id:

  identifier for shiny reactive

- main_par:

  main parameters

- traitStats:

  static object

- panel_name:

  name of panel

## Value

reactive input
