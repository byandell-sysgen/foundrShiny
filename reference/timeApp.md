# Times Panel App

Times Panel App

## Usage

``` r
timeApp()

timeServer(id, main_par, traitData, traitSignal, traitStats)

timeInput(id)

timeUI(id)

timeOutput(id)
```

## Arguments

- id:

  identifier for shiny reactive

- main_par:

  reactive arguments

- traitData, traitSignal, traitStats:

  static objects

## Value

nothing returned
