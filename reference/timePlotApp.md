# Time Plots App

Time Plots App

## Usage

``` r
timePlotApp()

timePlotServer(id, panel_par, main_par, traitSignal, time_table)

timePlotOutput(id)
```

## Arguments

- id:

  identifier for shiny reactive

- panel_par, main_par:

  reactive arguments

- traitSignal:

  static object

- time_table:

  reactive object

- responses:

  possible types of responses

## Value

nothing returned
