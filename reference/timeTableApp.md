# Times Tables App

Times Tables App

## Usage

``` r
timeTableApp()

timeTableServer(id, panel_par, main_par, traitData, traitSignal, traitStats)

timeTableInput(id)

timeTableUI(id)

timeTableOutput(id)
```

## Arguments

- id:

  identifier for shiny reactive

- panel_par, main_par:

  reactive arguments

- traitData, traitSignal, traitStats:

  static objects

## Value

nothing returned
