# Trait Solos App

Trait Solos App

## Usage

``` r
traitSolosApp()

traitSolosServer(id, panel_par, main_par, trait_table)

traitSolosOutput(id)
```

## Arguments

- id:

  identifier for shiny reactive

- panel_par, main_par:

  reactive arguments from \`server\`

- trait_table:

  reactive objects from \`server\`

- input, output, session:

  standard shiny arguments

## Value

reactive object
