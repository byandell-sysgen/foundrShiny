# Volcano Plot App

Volcano Plot App

## Usage

``` r
volcanoApp()

volcanoServer(id, panel_par, plot_par, plot_info, contrast_table)

volcanoOutput(id)
```

## Arguments

- id:

  identifier

- panel_par, plot_par:

  input parameters

- plot_info:

  reactive values from contrastPlot

- contrast_table:

  reactive data frame

## Value

reactive object
